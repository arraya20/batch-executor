Pharos Mainnet Batch Executor

Read-only preflight on Pharos Pacific Mainnet (chain ID 1672). It simulates the individual calls and combined Multicall3 transaction, then prepares unsigned transaction data only. It never signs or sends.

The sender address is simulation context only; it does not prove account ownership. Mainnet state may change after the simulation.

Batched subcalls run from Multicall3, not from the sender. Standard token transfers and sender-dependent claims may behave differently; native transfers are not supported.
